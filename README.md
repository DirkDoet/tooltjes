# Tooltjes

Kleine HTML-tools van Dirk Doet. Gebouwd en gereviewd via Finn-loop
(Linear + GitHub + Claude Code).

## Tools

- `index.html` — startpagina met overzicht
- `youtube-transcript.html` — plak een YouTube-transcript en maak er in één klik doorlopende platte tekst van (zonder tijdcodes) op je klembord; volledig client-side
- `ai-ready-check.html` — vul een website-URL in en krijg een AI-ready score met verbeterpunten; roept de `ai-ready-check-worker` (Cloudflare Worker) aan

## Finn-loop skills
